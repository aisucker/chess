# Mini Chess ♟️

Небольшой веб-проект с шахматами для двух игроков на одном устройстве.

## Возможности

- Правила шахмат, включая шах, мат, пат, рокировку, взятие на проходе и превращение пешки.
- Подсветка допустимых ходов и история партии.
- Отмена ходов, новая партия и переворот доски.
- Адаптивный дизайн для телефона и компьютера.

## Как запустить

Откройте файл `index.html` в браузере или включите **GitHub Pages** в **Settings → Pages → Deploy from a branch → main / (root) → Save**.

Проект написан на HTML, CSS и JavaScript. Шахматный движок chess.js загружается через CDN, поэтому для начала игры необходим доступ к интернету. Сборка и установка пакетов не требуются.
